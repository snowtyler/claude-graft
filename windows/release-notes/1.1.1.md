Claude Graft 1.1.1 for Windows no longer needs .NET installed, takes much less space, and works with the new packaged Claude Desktop.

## New

**Works with the packaged Claude Desktop.** Claude Desktop now installs from an MSIX package by default. Graft finds it and starts it either way, and profile data stays in the usual AppData folder.

**First-run guidance.** Until Claude Desktop is installed and signed in, the window and the flyout show what to do next instead of an empty list of profiles, and move on by themselves once it's done. A profile that isn't signed in shows Sign In on its Open button. Extra profiles should sign in by email, because Windows always hands a Google sign-in back to the main Claude.

## Improved

- Profile shortcuts no longer need .NET 10 installed. They used to send you to a download page the first time you opened one. The launcher now runs on the same runtime Graft already carries, and shortcuts made by earlier versions are moved over the first time 1.1.1 starts.
- Graft takes several hundred MB less space on disk. It no longer keeps a second copy of the sidebar-sync runtime for its shortcuts, and it leaves out parts of that runtime and of Windows App SDK it never uses.
- The installer now carries its version number in its file properties.

## Fixed

- Deleting a profile's data no longer crashes Graft when Claude has left files locked or read-only.
- Graft now quits when Windows ends the session or an installer asks it to close, so setup no longer waits for it to time out.
