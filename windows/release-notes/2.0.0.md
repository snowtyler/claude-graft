Claude Graft 2.0.0 for Windows catches up with the Mac's 2.0: shared usage between accounts, a sidebar with Artifacts, Projects and Search across every account, and a taskbar strip and chime for Claudes in the background.

## Upgrading from 1.1.x

Download `ClaudeGraftApp-win-Setup.exe` from this release and run it; 1.1.x's update check will not offer it. There is no need to uninstall 1.1.x first, and it is better not to: the new setup takes over its shortcuts. Shortcuts, profiles, settings and shared chats carry over unchanged.

Graft now installs to a new folder, `%LOCALAPPDATA%\ClaudeGraftApp`, with a new installer that downloads only what changed in later updates. The old folder is replaced by a link to the new one, so anything pinned to it keeps working, and Graft appears once in Apps & features.

One change: **Graft's own updates now install by themselves.** To keep pressing Install yourself, turn on "Hold Graft's updates" under Settings, Updates.

## New

**Shared usage.** A Claude can borrow from other accounts when its own runs low. Choose which on its page; a local relay picks the account with room for each request and keeps a conversation where it started. The tray flyout shows which account answers each conversation and lets you move it. Uninstalling Graft puts every Claude back as it was.

**A sidebar.** Every Claude gets its own page, and three pages work across all your accounts: **Artifacts** (list, share, export), **Projects**, and **Search Chats**. They sign in to claude.ai with an emailed code.

**Usage on the taskbar.** An optional strip beside the notification area shows the Claude in front, its usage and the conversation on screen, with a green dot when a turn finishes and a yellow one when it waits on you.

**A chime when a Claude is ready.** Optionally, a soft sound when a background Claude finishes, and a stronger one when it needs a permission or an answer. It adds one entry to Claude Code's settings, removed again when turned off.

**Claude Desktop updates from Graft,** without closing anything until you restart. Graft can also stop Claude updating itself mid-task.

**Shortcuts look like themselves,** each with its own colour, icon and taskbar button.

**Themes.** Pick a colour scheme, light or dark mode, and a backdrop.

## Improved

- Settings has three pages, and the tray flyout matches the Mac's.
- Chat sharing merges changes from both sides instead of letting one win, and shares project order.
- Accounts with no five-hour limit no longer read as 0%.
- Every control is named for screen readers.

## Fixed

- A file that couldn't be read was treated as empty, which could delete a shared chat or overwrite the shortcut list. Graft now leaves it alone.
- Folder paths are compared the way Windows does, ignoring case.

## Known limits

- The taskbar strip's hover border is tuned for a dark taskbar.
- The chime only covers Claude Code settings kept in your user folder's `.claude`.
