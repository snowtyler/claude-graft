Claude Graft 1.1.3 for Windows makes plan usage honest about how current it is, and gets sidebar sync working again.

## Improved

**Usage says how old it is.** Each profile now shows when its usage figure was last updated, when a refresh is running, and why one was turned away. An old or refused figure is drawn faint rather than passed off as current, and countdowns keep moving between refreshes.

- When the usage service rate-limits Graft, Graft now waits before asking again instead of asking on every tick, which kept the limit in place. Refresh says it is being held off rather than doing nothing.
- The last live figure is kept across restarts, so Graft no longer falls back to weeks-old history and shows 0%.
- A five-hour window whose reset time has passed now reads as closed straight away.
- The usage bars no longer replay their animation every time the flyout opens or Refresh is pressed. They only move when the numbers do.
- Opening the tray no longer counts as asking for a refresh, which was earning refusals.
- The profile cards are tidier: the details line up under the profile name with a little more room between them.

## Fixed

- Sidebar sync failed every time since 1.1.1, because the installer left out a file the sync helper needs to start. It is back, and a release can no longer be built without it.
- The "Keep the 5-hour window open automatically" checkbox could untick itself when the profile list reloaded. It now changes only when you click it.
