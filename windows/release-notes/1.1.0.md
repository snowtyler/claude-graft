Claude Graft 1.1.0 for Windows is the first update since 1.0.0, and the first one that can arrive by itself: from this version on, Graft checks for new releases and offers to install them.

## New

**Updates.** Graft now knows its own version and checks this repository's releases for a newer Windows build. When one is waiting, the tray icon, the flyout and the settings page say so, and a notification offers Install and Dismiss. Nothing installs without a press. If you're coming from 1.0.0 you'll need to install this release by hand, because 1.0.0 couldn't check for updates.

**Pinned chats and Code sort order are shared.** Profiles that share a chat history used to keep their own pins and sort order, so pinning a chat in one did nothing to the other. Now, when a shortcut opens a profile and every profile on that history is closed, Graft combines the pins and ordering and writes them back to each profile. An unpin carries across as well. If anything is uncertain, such as a profile still open or a database that won't open, Graft leaves both sidebars as they were and tries again next time.

**Recovering chats after an account switch.** Signing out of one account and into another inside a single Claude leaves the first account's chats behind in that profile. A profile now finds chats another profile holds for the account it's signed into, and offers to bring them over. The copy only adds chats and never removes anything from the other profile.

**Keep a five-hour window open.** Each profile has an optional setting, off by default, that starts a session whenever that profile's five-hour window has closed, so the clock is always running. It only acts on a live reading that says no window is open, and it waits half an hour between attempts.

**Fable weekly usage.** Accounts with a Fable weekly limit now show it under the weekly bar, in both the window and the tray flyout.

## Improved

- MCP servers from the source profile are now shared with grafted profiles. The desktop settings file was never actually shared on Windows, and linking it would have let one profile overwrite the other's permission choices. The source's missing servers are now copied into the profile's own file, and its existing grants and definitions are left alone.
- Usage figures stay current. A reopened window reads them again, and a first read that failed because the network wasn't up yet is retried. Refresh Usage stays disabled until every figure has arrived.
- Start Session is no longer stuck disabled when a usage reading fails.
- The window now shows the logo and a larger title, and the title bar no longer repeats them.
- The flyout and the title bar follow Windows when it switches between light and dark mode while Graft is running.

## Fixed

- Opening a profile could start an older Claude than the newest one installed, so Claude kept asking for an update it had already installed. The newest version is now chosen correctly.
- A profile could open to a "Couldn't load app settings" error. Its settings are now kept as the profile's own file rather than a link Windows couldn't read.
- A chat started in one profile and followed straight away by opening a second profile could show up as a stray duplicate in the second profile.
- Saving settings no longer turns off keeping Claude's own profile's five-hour window open.
- A crash during startup now leaves a record in Graft's diagnostics log instead of disappearing without a trace.
